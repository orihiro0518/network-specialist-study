記述式

Webシステムの冗長化

Internet │ [ Firewall ] │ [ Load Balancer ] ├──────┐ [Web1] [Web2] └──┬───┘ [ DB ]

問題

Web1に障害が発生した際、利用者への影響を小さくするため、ロードバランサが行うべき代表的な制御を説明してください。

解答例：Web1へのヘルスチェックで障害を検知し、Web1を負荷分散対象から外してWeb2へ通信を振り分ける。

試験ポイント：午後問題では「機器名」だけでなく、「何を検知し」「どう制御し」「結果どうなるか」まで書くと得点につながりやすい。
